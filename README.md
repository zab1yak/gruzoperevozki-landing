# gruzoperevozki-landing

Лендинг компании грузоперевозок в Перми. Только фронтенд: Vite + TypeScript, без фреймворка и без бэкенда.

**Сайт:** https://zab1yak.github.io/gruzoperevozki-landing/

## Запуск

Нужен Node.js LTS.

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # проверка типов и сборка в dist/
npm run preview  # посмотреть собранную версию
npm run lint     # ESLint
npm run format   # Prettier
```

## Тексты и данные

Все тексты, цены, контакты и списки лежат в одном файле: [`src/content.ts`](src/content.ts). Чтобы заменить данные на настоящие, правьте только его.

**Примерные данные (придуманы для макета, перед запуском заменить):**

- название компании «Груз59», телефон, e-mail, адрес и координаты;
- цифры в блоке «Цифры» (1 400 заказов, 6 машин, оценка 4,9, 87 отзывов);
- услуги и цены «от ... ₽/час»;
- автопарк: модели, грузоподъёмность, объём кузова;
- отзывы, имена авторов и даты;
- условия ответственности за груз и ответы в FAQ;
- подписи к фото-плейсхолдерам.

Данные из задания считаются настоящими: Пермь, опыт 2 года, часы работы (будни 10:00–22:00, выходные 10:00–20:00).

Кроме `src/content.ts`, название, описание и телефон продублированы в [`index.html`](index.html) (title, description, Open Graph, noscript) и в картинке [`public/og-image.png`](public/og-image.png). При замене данных обновите и их.

## Деплой

Сайт публикуется на GitHub Pages через GitHub Actions ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)) при каждом push в `main`. Vite собирает с `base: '/gruzoperevozki-landing/'`.

Один раз включите в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Шрифты

Референсы изучены по живым страницам, картинки и тексты с них не берём.

| Роль                      | Шрифт                                                              | Почему                                                                                                                                                                                                                      |
| ------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Заголовки и крупные цифры | [Inter Tight](https://fonts.google.com/specimen/Inter+Tight)       | topcarauto.ru набирает заголовки в SF Pro: плотный гротеск, вес 500, трекинг около -0.02em. Inter Tight ближайший бесплатный аналог с кириллицей, на больших кеглях держит плотный межбуквенный и хорошо читается в цифрах. |
| Текст, подписи, кнопки    | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | lkstr.ru ставит основной текст и подписи капсом моноширинным JetBrains Mono. Берём тот же шрифт, он есть в Google Fonts с кириллицей и даёт техничную тёмную подачу.                                                        |

Контраст пары: H1 от 160px на desktop против текста 15–16px, это примерно x10.8. Шрифты подключены через `@fontsource-variable`, без запросов к внешним серверам.

Из tgk-auto.ru берём приёмы, не гарнитуру: шапку в одну линию, плашки со срезанными углами, плашку гарантии, рейтинг с аватарами, объект крупным планом.
