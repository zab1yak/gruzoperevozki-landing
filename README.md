# НА КОЛЕСАХ

[Открыть сайт](https://zab1yak.github.io/gruzoperevozki-landing/) · [Дизайн в Figma — компьютер](https://www.figma.com/design/ktBYHK0oEAtfkYvnPBv4rv?node-id=6-11) · [Дизайн в Figma — телефон](https://www.figma.com/design/ktBYHK0oEAtfkYvnPBv4rv?node-id=6-387)

Лендинг перевозчика из Перми на Vite и TypeScript. Сайт показывает автопарк и ориентировочную стоимость, помогает подготовить детали поездки и связаться с Дмитрием или Павлом по телефону. Рабочая версия основана на коммите `07e16f8`. Результаты проверки от 23 ноября 2026 года собраны в [отчёте](docs/frontend-review.md).

## Что посмотреть

1. В калькуляторе выберите Газель 6,2 м. Два часа по Перми дают 3 000 ₽, а 100 км в режиме «Межгород» — 6 000 ₽.
2. Нажмите «Выбрать машину». В форме уже выбрана длинная Газель. Заполните маршрут тестовыми данными, подготовьте детали и проверьте сводку для звонка.
3. Сравните этот сценарий на телефоне и компьютере с макетом Figma. В репозитории тарифы хранятся в [src/content.ts](src/content.ts), расчёт реализован в [calculator.ts](src/components/calculator.ts), а сценарий проверяется в [e2e.ts](scripts/e2e.ts).

## Локальный запуск

Для проверки использовался Node.js 24.22.3. Команды выполняются из корня проекта.

```sh
npm ci
npm run dev
```

Vite выведет локальный адрес. Для просмотра сборки выполните `npm run build`, затем `npm run preview`.

## Данные и сценарии

- Телефоны, направления, перечень услуг, характеристики и тарифы машин находятся в [src/content.ts](src/content.ts). Статические метаданные, карточка ссылки и телефоны для посетителей без JavaScript также указаны в [index.html](index.html).
- Для Газели 4 м действуют ставки 1 100 ₽/ч и 45 ₽/км. Для Газели 6,2 м — 1 500 ₽/ч и 60 ₽/км. Минимальный городской заказ составляет два часа. Межгород считается по введённому километражу, итог согласуется по телефону.
- Выбор в калькуляторе или карточке переносит машину в форму. Имя, адреса, время, телефон и комментарий остаются в памяти текущей страницы. Посетитель может скопировать сводку и позвонить. Время подачи интерпретируется по Перми.
- При приближении к контактам загружается интерактивная Яндекс Карта с центром в Перми. Внешняя ссылка доступна независимо от загрузки виджета.
- Заявки в MAX, ссылки на соцсети и реальные отзывы можно добавить после получения данных. Стоимость грузчиков, допустимую нагрузку длинной Газели и условия межгорода нужно уточнить у владельца.

## Изображения и типографика

В [public/images](public/images) лежат три оригинальные иллюстрации, созданные в ImageGen. `transport.webp` используется на первом экране, `fleet-short.webp` и `fleet-long.webp` — в карточках. При замене на реальные фото обновите подписи, альтернативный текст и [public/og-image.png](public/og-image.png).

Локальный вариативный Inter содержит кириллицу. Лицензия SIL Open Font License включена в [public/inter-OFL.txt](public/inter-OFL.txt). Шрифты, изображения и стили загружаются вместе с сайтом. Палитра, размеры и отступы заданы в [src/styles/tokens.css](src/styles/tokens.css).

## Проверки

```sh
npx playwright install chromium
npm run lint
npm run build
npm run e2e
npm run shots
npm run a11y
```

Браузерные скрипты поднимают отдельный сервер собранной версии на свободном порту. Скриншоты и отчёт axe сохраняются в каталоге `screenshots/`. E2E проверяет пять размеров экрана, тарифы и переключения, ошибки формы, копирование, навигацию, FAQ и резервную ссылку карты при сетевом отказе.

## Публикация

GitHub Actions публикует ветку `main` на GitHub Pages. Текущий `base` в [vite.config.ts](vite.config.ts) — `/gruzoperevozki-landing/`. Статический результат находится в `dist/`. Для корня собственного домена выполните `npx tsc`, затем `npx vite build --base=/`. При смене домена также обновите canonical и абсолютные Open Graph URL в `index.html`.

Публикация подготовленной ветки требует решения владельца проекта. [Репозиторий](https://github.com/zab1yak/gruzoperevozki-landing) · [GitHub Pages](https://zab1yak.github.io/gruzoperevozki-landing/).
